# Язычок — памятка для Claude

Домашнее приложение для ежедневных логопедических занятий Лены с дочкой **Александрой** (7 лет, 1 класс, немецкая школа).
Тренируем свистящие и шипящие звуки (С, З, Ц, различение С–Ц и др.), плюс раздел «Школа» для 1 класса.

## Общение и правила

- С Леной — **по-русски**, коротко и по делу. Итог работы — 1–3 предложения: что изменилось и где это найти.
- Девочку называем только **«Александра»**. Никогда не «Саша» и не другие уменьшительные — ни в коде, ни в озвучке, ни в чате.
- Большие задачи доводим до конца. Если работа прервалась на лимитах — после сброса продолжаем, пока всё не сделано и не проверено.
- В репозитории не должно быть резервных копий (`yazychok-backup-*.json`), записей голоса ребёнка и фото: всё это хранится только в браузере.

## Как приложение работает

- Запускается **локально через `file://`** в Edge/Chrome на ноутбуке Лены (Windows 11): двойной щелчок по `index.html`.
  Без сервера, без интернета, без сборки.
- **Только классические скрипты**: никаких ES-модулей, бандлеров, npm-зависимостей и CDN во время работы приложения.
- `index.html` и `desktop-launcher.html` подключают фиксированный список файлов (старый ярлык на рабочем столе), их **не трогаем**.
  Новые модули добавляются в загрузчик `js/app.js` (порядок важен: данные → логика → экраны → `main.js`).
  `npm run smoke` проверяет, что всё подключено и синтаксис верен.
- Данные ребёнка — в браузере: `localStorage['yazychok-v2']` (состояние), IndexedDB `yazychok-v2` (хранилища voice / child / assets: мамины записи, записи ребёнка, картинки героя и подарка) и старая база `alexandra-voice`.
  **Ключи и имена баз не переименовываем, поля состояния не удаляем.** Новые поля — с умолчаниями в `core.normalizeState`.
  Резервная копия и импорт («Для мамы» → «Данные») должны продолжать работать (`tests/backup.test.cjs`).
- Эмодзи у Лены рисуются шрифтом Windows 11 (Fluent). Питомцы, наряды и игрушки — картинками из `js/emoji-art.js`, чтобы выглядели одинаково везде.

## Принципы для ребёнка (важно для любых новых экранов)

- **Без спешки и давления.** Ничего не дёргается и не подгоняет. Ожидание выбора — через `ui.tapWait`: через ~25 с тихий повтор задания, позже мягкая подсказка. Авто-нажатие — только для простых действий («крутить колесо»).
- Всё, что ребёнок должен понять, **звучит голосом**: Александра только учится читать (по-русски и по-немецки).
- Ошибка — мягко: вариант гаснет, «попробуй ещё», после двух ошибок подсвечиваем правильный ответ.
- Крупные кнопки и картинки, ноутбук 1366×657 — экран не должен прокручиваться в задании.
- Награды: звёзды → магазин; за занятие — деталь пазла, наклейка, глава сказки. «Школа» даёт не больше 25 звёзд в день.

## Как добавить…

- **Игру занятия**: запись в `core.GAMES` (`title`, `icon`, `min` — минимальный уровень звука, `speak` — говорит ли ребёнок, `hero`), `case` в `gamePayload`, условие в `gameIsPlayable`, обработчик `Y.games.<id> = async (stage, step, api) => ({ stars })`, фраза-заставка `LINES['g.<id>']`, стили, ветка в `DRIVER` в `scripts/diagnostics/autoplay.cjs`, тест в `tests/core.test.cjs`.
- **Игру с героем**: то же с `hero: true` в `js/hero.js`; реплики — `HERO_LINES` (голос героя).
- **Школьное задание**: генератор в `school-core.js` (`GENERATORS`), отрисовка `R.<тип>` в `school.js`, фразы de/ru в `school-data.js`, тест в `tests/school.test.cjs`.
- **Вещь в магазин**: `core.ITEMS`; картинка — имя в `scripts/emoji/build.py` (`NAMES`) и пересборка `js/emoji-art.js`; для нарядов — мерка в `WEAR_FIT` (`js/face.js`) и проверка на всех питомцах.
- **Любая новая фраза** → нужна озвучка (см. ниже), иначе упадёт тест «у каждой фразы есть готовая озвучка».
- Новое для Лены — коротко простыми словами в `README.md` («Что нового») и в подсказке «Как это работает — коротко» (`js/parent.js`).

## Озвучка (Silero, всё офлайн)

Голоса: **xenia** — приложение, **aidar** (тон ×1.3) — герой, **baya** (×1.22) — питомец, **eva_k** (`v3_de`) — немецкая «Школа».

```bash
export TTS_WORK=/tmp/tts && mkdir -p $TTS_WORK
pip install torch numpy ruaccent          # ffmpeg тоже нужен
curl -L -o $TTS_WORK/v5_5_ru.pt https://models.silero.ai/models/tts/ru/v5_5_ru.pt
curl -L -o $TTS_WORK/v3_de.pt  https://models.silero.ai/models/tts/de/v3_de.pt
python3 scripts/tts/unpack.py              # готовые клипы из js/audio-pack-*.js → $TTS_WORK/clips
node scripts/audio-lines.cjs > $TTS_WORK/lines.json
python3 scripts/tts/stress.py              # ударения (ruaccent) + ручные поправки FIX / WORD_FIX
python3 scripts/tts/gen.py < /dev/null     # озвучивает только недостающие клипы
python3 scripts/tts/pack.py                # → js/audio-pack-*.js
```

- Клип = `md5(ключ)[:16].mp3`. Если текст фразы изменился, а ключ тот же — удалите её клип в `$TTS_WORK/clips` перед `gen.py`.
- После `stress.py` **проверьте ударения** новых русских фраз (поле `stressed` в `lines.json`) и поправьте в `WORD_FIX`/`FIX`.
- Немецкие слова проверяйте распознаванием (faster-whisper, модель `small`, по 6 слов подряд); трудные — через `deTts` в `school-data.js`.
- Отдельные слоги немецкий голос произносит плохо — заданий «услышь слог» не делаем.

## Проверка перед тем, как отдать

```bash
npm test            # node:test, все тесты должны проходить
npm run smoke       # файлы, загрузчик, синтаксис
npm i -g playwright # один раз; Chromium в облаке уже есть в /opt/pw-browsers
MODE=session node scripts/diagnostics/autoplay.cjs        # целое занятие с фейковым микрофоном
MODE=games GAMES=heroHide,beads MICS=none node scripts/diagnostics/autoplay.cjs
MODE=school LANGS=de TYPES=lesson,math node scripts/diagnostics/autoplay.cjs
MODE=extra | MODE=screens; THEME=tale|games|mixed|mic; REALISTIC=1
```

Скриншоты попадают в `../shots` — **смотрите их глазами**, особенно новые экраны (1366×657 и узкий экран).
В конце прогона должно быть `NO ERRORS`.

## Как Лена получает обновления

Папка `Desktop/yazychok-alexandra` на её ноутбуке — клон этого репозитория. После изменений на GitHub она нажимает
**Fetch/Pull** в GitHub Desktop (или `git pull`) и обновляет страницу в браузере (Ctrl+F5). Прогресс Александры хранится в браузере и не теряется.

Идеи и задачи на будущее — в `IDEEN.md`. Берём одну задачу за раз, отмечаем сделанное.
