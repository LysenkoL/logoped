## Упражнения и игры для звуков

- [ ] «Светофор звуков»: С или Ц? Зелёный — С, красный — Ц (различение, как у логопеда).
- [ ] Звук в потоке речи: «Поймай звук в предложении» — герой читает фразу, ребёнок хлопает, когда слышит С.
- [ ] «Расскажи по картинкам»: 3 картинки подряд → своя фраза (связная речь со звуком).
- [ ] Скороговорки с темпом: медленно → средне → быстро, с метрономом и записью своего голоса.
- [ ] Слоги со стечением согласных (СТ, СК, СП, СЛ) как отдельный уровень между «слогами» и «словами».
- [ ] Ещё 2–3 игры с микрофоном (длинный звук, короткие повторы), каждая — со своей картинкой и героем.
- [ ] Упражнения гимнастики: анимация язычка покадрово (сейчас — SVG-лицо), «песочные часы» вместо цифр.

## Любимый герой

- [ ] Герой рассказывает короткую историю, где Александра вставляет слова (говорит вслух).
- [ ] «Герой в магазине»: просит купить вещи со звуком, считает монетки.
- [ ] Герой учит немецкому: слово по-немецки — Александра говорит по-русски, и наоборот.

## Школа (1 класс)

- [ ] Письмо: обвести букву пальцем/мышкой по точкам (Druckschrift), с проверкой линии.
- [ ] Часы (volle / halbe Stunde), деньги (Euro / Cent), формы, rechts / links, Zahlen bis 100.
- [ ] Чтение: слово ↔ картинка, короткие предложения «Wer? Was?» с выбором картинки.
- [ ] Звук → буква (как в Anlauttabelle Pusteblume): услышать первый звук слова и найти букву.
- [ ] Собрать слово из букв (простые слова: Mama, Oma, Sofa, Rose).
- [ ] Статистика школы для мамы: что получается, что трудно.

## Интерфейс

- [ ] «Для мамы» — длинная страница → вкладки (Ребёнок, Звуки, Школа, Голос, Данные).
- [ ] Быстрее первая загрузка: аудиопакеты и модель распознавания подгружать только когда нужны.
- [ ] Проверить и подогнать под тачскрин/планшет (крупные цели, без наведения мышкой).
- [ ] По желанию: версия для телефона/планшета (PWA на Netlify). Прогресс тогда переносится через резервную копию.
